# ThaibaHive Project & Agent Instructions

## Policy: Matt Pocock Engineering & Productivity Skills

This workspace enforces **Matt Pocock's Engineering & Productivity Skills Suite** on all tasks:

1. **Mandatory Application**: Always utilize the relevant engineering (`ask-matt`, `grill-with-docs`, `domain-modeling`, `to-spec`, `to-tickets`, `implement`, `tdd`, `codebase-design`, `diagnosing-bugs`, `code-review`, `pr`, `retro`) and productivity (`grill-me`, `handoff`, `teach`, `to-questionnaire`, `wait-what`) skills.
2. **Workflow Pipeline**: Follow the Idea → Ship progression: Clarify (`grill-with-docs`) → Formalize (`to-spec`) → Decompose (`to-tickets`) → Build (`implement` + `tdd`) → Verify (`code-review`).
3. **No Skipping**: Do not jump to unverified code modifications without establishing test seams and verifying behavior.
4. **Router**: For any routing decisions, consult [`ask-matt`](.agent/skills/ask-matt/SKILL.md).
