# ADR-015: Administrative Job Management API

* **Status:** Accepted
* **Date:** 2026-08-07

## Context & Problem
Administrators require control over database-backed queued compiler tasks (trigger, pause, resume, cancel) with proper RBAC constraints and audit logging.

## Options Considered
1. **Direct database CLI mutations**: Forcing operators to manually edit rows via terminal SQL. (Unsafe, un-audited, high risk).
2. **REST API gated with Role-Based Access Control and Preference Auditing (Chosen)**: Exposing endpoints gated to `super_admin` role that validate input schemas, manage conditional status transitions, and log actions to the preference audit log.

## Decision
Adopt Option 2.

## Rationale
Exposing secure REST endpoints ensures administrative operations are safe, validated by Zod schemas, and compliant with audit logging protocols by writing to `preference_audit_log`.

## Consequences
Manual enqueuing triggers a background processing cycle. Invalid state transitions (e.g. pausing an already processing task) are rejected.
