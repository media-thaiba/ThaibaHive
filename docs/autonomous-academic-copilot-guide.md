# Autonomous Academic Copilot & Advising Guide

## Overview
The Autonomous Academic Copilot combines deterministic evaluation with natural language explainability.

## Core Capabilities
1. **Deterministic Degree Progress Audit:** Evaluates completed vs. required credit distribution and GPA.
2. **Prerequisite & Constraint Solver:** Enforces hard/soft prerequisites and balances course workloads.
3. **Multi-Agent Tool Calling:** ReAct loop executing dedicated advisory tools with step-by-step transparency.
4. **Academic Intervention Gating:** Flags student risk tiers and routes complex cases to human counselor review.
