# Privacy-Preserving Cross-Campus Benchmarking Guide (IPEDS/HESA)

## 1. Indicator Specifications
1. **Retention Rate (%)**: Cohort continuation percentage across academic terms.
2. **Graduation Rate (%)**: 4-year / 6-year completion rate.
3. **Student-to-Faculty Ratio**: Full-time equivalent student headcount per faculty member.
4. **Instructional Expenditure per Student ($)**: Total departmental spend / FTE.
5. **Energy Efficiency Index**: kWh / Square Meter of operational campus facilities.
6. **Mean Cumulative GPA**: Grade point average across active enrolled cohorts.

## 2. SMPC Ranking Protocol
Indicator percentiles and rankings are computed using Shamir secret sharing. No institution exposes absolute headcount, operational budget, or individual student identities to peers.
