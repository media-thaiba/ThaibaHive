# Cryptographic Document Verification & Anti-Counterfeiting Runbook

## Overview
Every academic document generated by ThaibaHive is anchored with a deterministic SHA-256 canonical hash and an HMAC cryptographic signature.

## Verification Workflow
1. **QR Scanning**: Scanning the vector QR code on any certificate or hall ticket redirects to `https://<domain>/verify/<documentHash>`.
2. **Hash Resolution**: The resolver queries `docVerificationSignatures` and `docGeneratedRecords` tables.
3. **Signature Verification**: Verifies cryptographic HMAC-SHA256 signature against institutional master secret `DOC_SIGNING_SECRET`.
4. **Audit Counter**: Increments the public verification counter and logs timestamps.

## Revocation Procedure
To revoke an issued credential (due to disciplinary action or record correction):
```sql
UPDATE doc_verification_signatures
SET revoked = 1, revoked_reason = 'Disciplinary correction', updated_at = CURRENT_TIMESTAMP
WHERE document_hash = '<TARGET_HASH>';

UPDATE doc_generated_records
SET status = 'revoked'
WHERE document_hash = '<TARGET_HASH>';
```
Subsequent public scans will immediately return a `REVOKED` badge.
